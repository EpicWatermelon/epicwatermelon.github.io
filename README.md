# Zhengji Liu — Living CV

这是我的个人网页与持续生长的履历：[epicwatermelon.github.io](https://epicwatermelon.github.io/)。

我用 Codex 生成、整理并打磨了网站里的像素资产，也和它一起把这些夜空、角色和研究轨迹做成了这个网页。它记录我的研究、工程实践，以及仍在发生的下一步。

Codex 真牛逼。它是这次创作里非常可靠的搭档：能把模糊的想法变成可见的画面，也能耐心地一起把细节做对。

GPT 和 Codex 在这次创作里不只是“写代码的工具”。它们能理解一个还没说清的氛围，给出像素资产与交互的方向，把一团模糊的想法逐步变成能打开、能滚动、能继续生长的网页。它们也足够细致：会记住版本、处理缓存、守住本地资料不上传，并在每次改动后认真检查。真的很强。
