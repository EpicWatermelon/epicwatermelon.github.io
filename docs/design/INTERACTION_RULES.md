# 交互与彩蛋规则

这里记录用户已经确认的交互边界。修改相关功能前先核对本文件；新增或改变触发范围、点击次数、反馈顺序、文案、声音与结束行为时，同步更新记录和自动化测试。

## 00 / Saber 音乐彩蛋

- 仅在夜晚主题启用；白天场景使用 Malinois，Saber 与音乐触发区不显示。
- 连续点击 Saber 五次解锁并播放《孤独な巡礼》。
- 音乐开始后跨 01–05 章节持续播放，滚动离开 00 不触发暂停。
- 已解锁后再次点击 Saber 切换暂停与继续播放；标签页隐藏和页面离开时暂停，歌曲结束后可再次点击重播。

## 00 / 树木荧光彩蛋

- 仅在夜晚主题启用；白天不显示树木点击区，也不生成荧光。
- 前九次点击逐步增加从树冠随机位置落下的暖金与柔白荧光，第十次触发完整星雨。
- 每一批荧光独立完成下落与熄灭，后一次点击不清除前一次结果。

## 01–05 / 夜间舰队彩蛋

- 仅在夜晚主题启用；白天背景使用像素树叶，不绘制舰队。
- 仅在离开 00 首页后的夜间章节（01–05）生效；首页不绘制舰队。
- 每次从首页进入后续章节有 45% 概率触发；命中后随机等待 6–18 秒，再从两艘舰船中随机选取一艘，掠过约 7.2 秒。
- 月级巡洋舰从左向右作水平直线掠过；像素化休伯利安号从左上向右下穿越。
- 单次掠过结束后随机等待 24–60 秒才可能出现下一次；两艘舰船仅作为低频背景彩蛋，不遮挡内容阅读。
- 尊重 `prefers-reduced-motion`：启用减少动态时不出现舰船。

## 05 / Contact 文字彩蛋

- 当前语言范围：仅在中文界面（`html[lang="zh-CN"]`）启用。
- 英文界面不累计点击，不触发动效，也不点亮下方进度星；标题保持普通展示状态。
- 中文界面前五次点击依次点亮五颗像素星，并逐级增强标题的震动与尺寸反馈。
- 第六次点击完成聚光并解锁文字彩蛋；之后每次点击切换下一句。
- 最后一句“哎呀我去你不早说”使用 `clamp(5.5rem, 11.5vw, 11rem)` 的独立大字号，并叠加短促的强调震动、轻微旋转与亮度爆发；下一次点击恢复原标题。
- 英文版彩蛋留作后续独立设计，只有在用户明确确认方案后再实现。

## 维护约定

- 用户确认新的交互规则后，在实现当次就记录，不等待后续提醒。
- 语言范围属于功能规则，不能根据另一语言已有实现自行扩展。
- 规则变化需要先补失败测试，再修改页面行为。
