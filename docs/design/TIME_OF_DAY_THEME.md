# 昼夜主题规则

## 切换边界

- 页面读取设备本地时间：07:00–17:59 使用白天主题，其余时间使用夜晚主题。
- 本地检查可使用 `?theme=day` 或 `?theme=night` 强制主题；显式参数优先于设备时间。
- `html[data-scene-theme]` 是 CSS 与运行时绘制的共同状态源，浏览器 `theme-color` 与之同步。

## 00 场景

- 夜晚保留现有星空、夜树、草地、Saber、树木星雨、坠落荧光与 Saber 音乐彩蛋。
- 公开夜景与 Night Scene Studio 使用 `tree-sway-v2` 八帧树动画；第 1、5 帧保持批准静止树，树干、根系和主枝固定，其余帧只移动树冠叶片。树冠中央保留深蓝承托叶影，移动叶缘不得在枝干旁露出透明夜空。夜景的树、草与 Saber 待机帧使用 `260ms`；日景草地保持第 3 档、`180ms`。两种主题的节奏独立，禁止用全局常量覆盖夜景。
- 白天公开场景使用 `sky-day-v2`、`ground-foundation-day-v1`、`tree-day-v2` 与 `meadow-day-wind-v7`；树木保持静态，草地维持第 3 档、`180ms` 节奏。Day Scene Studio 使用 `tree-day-pixel-wind-v2` 的内部承托、后叶、固定枝干和前叶四层 Canvas 风动树，并从 `meadow-day-v1` 实时绘制独立草地 Canvas；Malinois 素材暂存于 `assets/pixel/home/`，当前页面与 Day Scene Studio 均不加载其图层或动画。
- 白天不初始化依赖夜景叙事的坠落荧光、树木星雨和 Saber 音乐触发器，避免隐藏控件仍可聚焦或触发。
- 白天与夜晚的 `1672×941` 天空、地基、树木和草地对应资产在所有响应式断点共享同一套场景坐标；禁止按主题单独移动对应图层，保证逐层一一对齐。
- 日景主页当前使用原始 `tree-day-v2` 静态树；禁止整棵树的 CSS 位移和未锁定原像素的 AI 帧。后续树冠精灵图只能通过蒙版编辑生成，且树干、根系和主枝必须与 `tree-day-v2` 逐像素一致，避免透明空区、边缘拖影及根系位移。

## 全站背景与颜色

- 夜晚背景保留星星、流星和 Background 低频舰队。
- 白天背景统一改为单色像素树叶；所有树叶只使用当前章节的 `leaf` 色，通过透明度、朝向和位置产生层次。单枚 Canvas 叶片限制在 2–3 个逻辑像素，首屏 DOM 叶片使用同级细粒度轮廓，禁止粗十字块。
- 01–05 使用鼠尾草绿、苔绿、薄荷绿和灰青绿组成的连续调色板；背景、面板与卡片都保留绿色倾向，不使用白色纸张表面。
- 白天保留夜间章节的金色/蓝色分工，再将每组颜色压暗为适合浅色背景的对应色：Education 使用紫蓝、Ophthalmic 使用青绿、Industrial 使用金棕与深青、Contact 使用琥珀与紫色。章节眉题、斜体标题、案例编号和操作标签跟随同一组语义变量，正常正文与其背景至少保持 4.5:1 对比度。
- 00 的白天场景仍保留深蓝天空，以维持现有像素资产的完整构图；标题继续使用暖白与日光金。

## 白天文字可读性

- 00 首页的角色说明与“进入履历”提示，以及 01–05 的章节导航，属于白天主题的高优先级可读信息。首页辅助文字使用纯白，绿色章节背景上的导航使用深松绿；保持与夜晚版相同的无底框、无阴影、无额外内边距结构。
- 00 深蓝天空中的章节导航继续使用高亮浅色文字；此规则只覆盖首页，进入绿色章节背景后恢复深色导航文字，保证两种场景都有稳定对比度。

## 动效与无障碍

- 白天树叶使用低速阶梯漂移；公开 00 的树保持静态，草地沿用八帧风动画。Day Scene Studio 的树冠使用整数条带位移，定稿默认值为最大摆幅 `6px`、条带高度 `4px`、循环时长 `3.0s`，并保留 `1px` 接缝护边；参数面板允许在 `0–6px`、`4–32px` 和 `2–7s` 范围内实时检查，恢复操作回到定稿值。树干、根系和主枝保持固定，遮盖层级预览按内部承托叶影 → 后层深绿叶 → 固定枝干 → 前层亮叶和枝梢显示，暂停只冻结树冠风动。
- Day Scene Studio 的草地与树冠共享最大摆幅、条带高度和循环时长，以 12fps 从原始草图重新采样；`y = 680–841` 为可动草尖区，`y = 842` 以下为固定草根与土层。所有偏移保持整数像素，相邻条带每帧最多相差 `1px`，接缝使用 `1px` 纵向护边。日间不显示旧的帧时长控制，Night Studio 的草地帧系统与控制保持独立。
- `prefers-reduced-motion: reduce` 下停止叶片漂移、Day Scene Studio 树冠与草地位移、场景帧动画、流星与舰队；Studio 风动树和草地回到零偏移静态帧，静态叶片仍保留为背景纹理。
- 日夜颜色过渡最长 300ms；主题在首屏脚本执行时确定，避免先闪出错误主题。
