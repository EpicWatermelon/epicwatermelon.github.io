## 昼夜主题

- 页面载入时按访客本地时间选择主题：07:00–17:59 使用白天，18:00–06:59 使用夜间。
- `?theme=day` 与 `?theme=night` 可覆盖自动判断，便于预览与视觉回归；浏览器主题色同步切换。
- 00 白天场景启用日间天空、树冠与草地风动、Malinois 待机动画；针对桌面和 375px 窄屏分别校准取景。
- 01–05 采用暖纸色、浅雾蓝、深青文字、叶绿与日光金组成的日间色板，并通过共享画布连续过渡。
- 白天画布与 00 前景仅生成单色像素树叶，停用流星、舰队、树木落光和 Saber 音乐彩蛋；夜间星空与现有彩蛋保持原样。
- `prefers-reduced-motion` 下树叶保持静止，昼夜图层依然正确切换。

## 马犬独占图层

- 首页日景与 Day Scene Studio 统一改为三层：`malinois-base-v1.png`、尾巴动画层和口部动画层。
- `malinois-base-v1.png` 从已确认的第二版马犬母图中挖除全部尾巴帧的像素并挖除口鼻区域；尾根和嘴部在任一时刻只由一个图层绘制。
- 新增 `malinois-head-pant-v9-00.png` 至 `-07.png`，仅保留口鼻、下颌与舌头的八帧变化。耳朵、身体和眼睛固定在底图上，避免 AI 帧间漂移或重影。
- 增加 `tools/build_malinois_rig.py`，可预览和重建底图、尾巴遮罩及口部切片；默认口部裁切框为 `(470, 335, 712, 455)`。
- 尾巴联合遮罩在挖空底图前转为二值透明蒙版，消除半透明边缘留下的重复像素。
- 八个马犬动画时刻都执行像素级互斥检查：底图、尾巴与口部的重合非透明像素必须为零。
- CSS 叠放顺序固定为底图 → 尾巴 → 口部；首页与 Studio 使用同一规则。
