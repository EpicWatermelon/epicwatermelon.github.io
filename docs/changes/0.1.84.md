## 参数定稿

- 昼夜场景共用已确认的构图参数：树木 `22.8 / 18.6 / 0.75 / z1`，Saber `62.1 / 68 / 0.48 / z3`，地基 `4.8 / 1.02 / 0.89 / z1`，草地 `9.3 / -5.2 / 0.65 / z5`。
- 夜间树、草与 Saber 待机帧固定为 `240ms`；Night Studio 草稿恢复值同步为最大摆幅 `3px`、条带高度 `8px`、循环时长 `3.6s` 和 `240ms`。夜间不显示日间条带风控制，这组条带值只用于保持复制配置完整。
