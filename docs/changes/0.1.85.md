## 日间主页树冠风动

- 修复日间主页仍只显示 `tree-day-v2.png` 静态树的问题；主页现在加载与 Day Scene Studio 相同的内部承托、后叶、固定枝干和前叶四层 Canvas。
- 主页固定使用已确认的最大摆幅 `6px`、条带高度 `4px`、循环时长 `3.0s` 与 `12fps`，树干、根系和主要树枝保持固定。
- 原始静态树继续作为加载及资源失败时的兜底；四层素材全部就绪后才切换显示，避免初始化阶段出现空树或双重树冠。
- `prefers-reduced-motion: reduce` 下回到零位移静态帧并停止动画帧循环。

## 日间紧凑导航可读性

- 在 `720px` 及以下，底部六段快速章节栏改为纯白 `#fff` 底色。
- 00–05 全部使用深金 `#8f671e`；当前章节继续以同色底部指示线标记。该深金在白底上的对比度为 `5.09:1`，保证手机端小字号仍清晰可读。
- 首页的高优先级导航颜色也由手机端规则覆盖，避免 00 回退为近白色。
- 桌面与平板右上角导航继续沿用绿色章节背景上的深松绿文本；该小屏覆盖只服务于纯白底栏。
- 静态资源缓存参数由 `0.1.84` 升级到 `0.1.85`，确保浏览器重新加载本次 CSS 配色。
